# traces-of-human-presence-in-space
Traces of Human Presence in Space is a one-page data visualisation that depicts all the objects (payload, debris and rockets) that are currently orbiting Earth or in a solar orbit. 

The visualisation uses part of the "General Catalog of Artificial Space Objects: Current Catalog" by Jonathan C. McDowell. In particular, it uses orbital parameters (perigee, apogee, and inclination), launch dates, operational status, and ownership data to spatialise over 33,000 artificial objects. The dataset is explored through a synchronised dual-view interface: a horizontal scatterplot mapping altitude over time, paired with a dynamic canvas projection that traces each object's orbit around Earth. The interactive filters and a density heatmap mode allow users to navigate the dataset, exploring the historical buildup of space debris and the geopolitical footprint of key space powers overtime.

The work was realised using D3.js and the HTML5 Canvas API, to ensure fluid rendering and interactions of all objects.
